## Drops requiring retroactive port

**None.** Every dropped commit is either fully subsumed by upstream
2.1.18 (sync, dep bumps, eslint cleanups, test fixups, deployment-config
disable) or its only effect is on log-line shape, which has no functional
or contractual impact on configuration sync behaviour.

## Operator follow-ups (non-blocking)

- Re-baseline any Grafana / Loki dashboard that keys on **literal log strings**
  emitted by `index.js` event handlers, the repository plugin, or the diffable
  base class. Field semantics are unchanged; only the surrounding boilerplate
  shifts to upstream's `pino`-native shape.
- The "events per minute" volume at `debug` level may rise; `info` level
  volume is unchanged or lower (upstream + `9e45612`-style trimming).
